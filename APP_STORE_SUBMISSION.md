# AttachMatch — App Store Submission Guide

## Prerequisites

| Requirement | Details |
|---|---|
| Mac with macOS 13+ | Required to run Xcode |
| Xcode 15+ | Free from Mac App Store |
| Apple Developer Account | $99/year — [developer.apple.com](https://developer.apple.com) |
| CocoaPods | `sudo gem install cocoapods` |
| Node.js 18+ | Already installed |

---

## Step 1 — Clone & install

```bash
git clone <your-repo-url>
cd AM
npm install
```

## Step 2 — Install iOS CocoaPods dependencies

```bash
cd ios/App
pod install
cd ../..
```

## Step 3 — Build the web app and sync to iOS

```bash
npm run cap:ios
# This runs: next build → cap sync → opens Xcode
```

## Step 4 — Configure signing in Xcode

1. Xcode opens automatically
2. Click **App** in the left sidebar → **Signing & Capabilities** tab
3. Set **Team** to your Apple Developer account
4. Change **Bundle Identifier** to `com.attachmatch.app`
   (or your preferred ID — must be unique in the App Store)
5. Xcode handles provisioning profiles automatically with "Automatically manage signing"

## Step 5 — Add App Icons in Xcode

1. In Xcode, open `App/Assets.xcassets` → `AppIcon`
2. Drag in your icon images (1024×1024 PNG required for App Store)
3. The `public/icons/icon-1024.png` file can be generated by running:
   ```bash
   node scripts/generate-icons.js
   ```
   (Already generates all sizes including 512px — scale up for 1024px manually
   or use [appicon.co](https://www.appicon.co) to generate all Xcode sizes at once)

## Step 6 — Test on simulator/device

```bash
# Or run directly in Xcode: ▶ button
```
In Xcode: Select an iPhone simulator → press **Run (▶)**

## Step 7 — Archive for App Store

1. Xcode menu: **Product → Archive**
2. Wait for build to complete
3. In the Organizer window: click **Distribute App**
4. Choose **App Store Connect** → follow prompts
5. Upload completes automatically

## Step 8 — Set up App Store Connect listing

Go to [appstoreconnect.apple.com](https://appstoreconnect.apple.com):

1. **My Apps → (+) New App**
   - Platform: iOS
   - Name: `AttachMatch`
   - Bundle ID: `com.attachmatch.app`
   - SKU: `attachmatch-001`

2. **App Information**
   - Category: **Lifestyle** (primary), **Social Networking** (secondary)
   - Age Rating: 17+ (Dating apps require 17+)

3. **Pricing**: Free

4. **App Store page — copy/paste ready:**

   **Subtitle** (30 chars):
   ```
   Find love, understand yourself
   ```

   **Description:**
   ```
   AttachMatch is the dating app built around attachment theory —
   the science of how we connect in relationships.

   Take our clinically-inspired quiz to discover your attachment style
   (Secure, Anxious, Avoidant, or Disorganized), then meet people whose
   style is most compatible with yours.

   FEATURES
   • Attachment Style Quiz — 20 questions based on the ECR scale
   • Compatibility Scoring — see your match % before you swipe
   • Hinge-style profiles — photos, prompts, and real personality
   • Style-based filtering — browse by attachment type
   • Compatibility Insights — understand why you match
   • Match & Message — connect with your best fits

   WHY ATTACHMENT STYLE?
   Research shows that understanding attachment patterns is one of the
   strongest predictors of relationship satisfaction. AttachMatch puts
   that science to work for your love life.
   ```

   **Keywords** (100 chars):
   ```
   dating,attachment style,relationships,secure,anxious,avoidant,psychology,love,match,hinge
   ```

5. **Screenshots** — Required sizes:
   - iPhone 6.9" (1320×2868) — at least 3
   - iPhone 6.5" (1242×2688) — at least 3
   - Use the iOS Simulator in Xcode to capture these

## Step 9 — Submit for review

1. Select your build in App Store Connect
2. Answer the export compliance questions (No encryption = Yes)
3. Click **Submit for Review**
4. Apple reviews in ~24-48 hours

## Android (Google Play)

```bash
npm run cap:android
# Opens Android Studio
```

In Android Studio:
1. **Build → Generate Signed Bundle/APK**
2. Choose **Android App Bundle (.aab)**
3. Create a new keystore (save it securely — you need it for every update)
4. Upload to [play.google.com/console](https://play.google.com/console)

## Updating the app

```bash
# Make code changes, then:
npm run build:mobile   # rebuilds web + syncs to both platforms
# Then archive again in Xcode / build in Android Studio
```
